## 领域设计指南：数据报表

本 Sub Agent 专注于把视图实现为**数据报表/统计页**。

### 页面结构（参考）

1. **页面头部**：报表标题 + 统计周期 + 刷新/导出操作（如需求需要）
2. **指标卡区（KPI 卡片）**：3~4 个核心指标，大号数字 + 指标名 + 环比/同比说明，可用语义色（涨绿跌红等）
3. **趋势/占比区**：可用简单的条状图（横向/纵向 bar）或环形占比呈现趋势，全部用纯 HTML+inline style 实现（无需图表库）
4. **明细表区**：数据明细用 `<table>` 呈现，表头浅色底、斑马纹可选、数字右对齐
5. **汇总说明**：底部可加结论性文字或注释

### 数据

- 依据用户需求描述的场景与维度生成合理示例数据（数值、占比、时间）
- 指标、表格列名要贴合业务语义

### 视觉

- 指标卡：大号数字（24~28px 加粗）+ 指标名（12~13px 浅色）+ 趋势标签
- 表格：表头 #f8fafc 底色、字号 13px、行高舒适、分隔线 1px solid #eef2f7
- 图表用 div + width/height 模拟条形，颜色保持统一主色系

### 注意

- 用 inline style 实现全部样式，禁止 class
- 执行要点（plan）会指明维度与内容层次，请参考
