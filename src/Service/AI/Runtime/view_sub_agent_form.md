## 领域设计指南：表单视图

本 Sub Agent 专注于把视图实现为**结构化表单**。

### 表单结构

1. **表单标题区**：标题 + 简短说明（用途、填写的注意事项）
2. **分组字段区**：把字段按业务分组（如"基本信息""联系方式"），每组一个卡片
3. **字段呈现**：每个字段包含标签 + 输入控件（输入框、文本域、下拉、日期、单选/复选等），用真实控件（`<input>` / `<textarea>` / `<select>`）呈现
4. **必填标记**：必填字段在标签后加红色 `*`
5. **操作区**：提交、重置等按钮，居中或右对齐

### 结合实体字段

- 通过 `view_getInfo(viewId)` 与 `view_listEntityFields(viewId)` 查看视图绑定的实体字段
- 优先使用真实字段名作为标签（可参考字段的 label），缺失的字段用合理示例字段补充
- 字段类型要与实体字段类型匹配（文本/数字/日期/单选等）

### 视觉

- 表单区域白底卡片，字段间距舒适（字段之间 14~18px）
- 标签清晰、字号 13~14px；输入控件高度 36~40px，边框 1px solid 浅灰，聚焦时可给主色边框
- 分组卡片之间留白，整体布局对齐工整

### 注意

- 用 inline style 实现控件样式，禁止 class
- 若需求未指定字段，依据视图绑定的实体字段与需求描述生成
- 执行要点（plan）会指明内容层次，请参考
