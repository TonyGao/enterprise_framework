## 领域设计指南：信息展示

本 Sub Agent 专注于把视图实现为**卡片化的信息展示页**。

### 页面结构（参考）

1. **页面头部**：标题 + 副标题/描述 + 状态标签（如"进行中""已完成"）
2. **概览卡片区**：核心摘要信息用横向卡片或双栏呈现
3. **详情分组区**：把信息按业务分组，每组一张卡片，内部用网格（2~3 列）排字段
4. **辅助操作区**：如有操作（查看、编辑、导出等），以按钮形式呈现

### 信息组织

- 通过 `view_getInfo(viewId)` / `view_listEntityFields(viewId)` 查看视图绑定实体字段，优先用真实字段组织
- 字段呈现：小号标签（11~12px，浅色）+ 字段值（14px，加粗偏深色）
- 关键信息可突出（加背景、加粗、主色），次要信息弱化

### 视觉

- 白底卡片 + 浅灰页面背景，卡片圆角 10~12px、边框 1px solid 浅灰、内边距 20px
- 卡片间距 14~16px；状态标签用圆角胶囊 + 对应语义色（成功绿/警告橙/错误红）
- 整体克制、信息密度适中，便于扫读

### 注意

- 用 inline style 实现全部样式，禁止 class
- 需求未指定字段时，依据绑定实体与需求描述生成
- 执行要点（plan）会指明内容层次，请参考
