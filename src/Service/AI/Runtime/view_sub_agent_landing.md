## 领域设计指南：品牌落地页

本 Sub Agent 专注于把视图实现为**强视觉、品牌化的落地/宣传页面**。

### 页面结构（参考）

1. **Hero 区**：大标题 + 副标题 + 主 CTA，通常配品牌主色渐变背景或装饰元素
2. **信任/价值区**：核心卖点、价值点用图标 + 标题 + 描述卡片横向排列
3. **内容区**：功能介绍、产品/服务说明，可图文混排
4. **数据/成果区**：数字指标（可用大号数字突出）
5. **CTA 区**：再次引导行动的按钮 + 收尾文案
6. **页脚**：品牌信息、版权、联系方式

### 品牌与视觉

- 依据需求提炼品牌调性（科技、稳重、活力、亲和等），选择主色与辅助色
- 善用渐变、大字号标题、留白营造视觉冲击；可用简单的几何装饰（圆角块、渐变光晕）提升质感，保持克制不杂乱
- 圆角、阴影统一，保证专业感
- 文字层级清晰：大标题 > 区块标题 > 正文 > 辅助说明

### 内容

- 依据用户需求组织真实内容与文案；需求未给细节时，使用合理示例品牌/产品文案补全
- 执行要点（plan）会指明内容层次，请参考

### 注意

- 用 inline style 实现全部样式，禁止 class
- CTA 按钮、卡片、指标等交互观感要完整
