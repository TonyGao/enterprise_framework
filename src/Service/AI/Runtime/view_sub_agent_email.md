## 领域设计指南：商务邮件

本 Sub Agent 专注于把视图实现为**正式、专业的中文商务邮件**。

### 邮件结构（按正式信函规范）

1. **主题/头部区**：明确的邮件主题（如"入职录用通知函"），可带公司品牌标识或氛围色头部
2. **称谓**：以"尊敬的 ××× 先生/女士："开头
3. **正文段落**：
   - 欢迎语/感谢语：感谢关注、认可，引出正式通知
   - 核心内容：职位、部门、入职时间、地点等关键信息
   - 后续安排说明：入职所需材料、报到流程等（视需求）
4. **关键信息呈现**：用卡片或表格把结构化信息（职位信息、入职安排、薪酬福利等）清晰呈现，便于阅读
5. **落款**：发件部门/人、联系方式、日期
6. **邮件底部**：系统自动生成提示、公司信息

### 措辞要求

- 语气正式、专业、尊重，符合中文商务信函习惯
- 措辞得体，避免口语化
- 示例数据（人名、职位、日期、部门）要合理真实，让成品像可实际发送的邮件

### 视觉

- 整体干净、企业化；头部可用品牌主色渐变增加正式感
- 正文区域白底、行距舒适（line-height 1.8~2），正文 14~15px
- 关键信息用浅色背景卡片 + 主色左边框或主色小标题，保持克制
- 颜色建议从同一品牌色系中选取，避免杂乱

### 注意

- 依据"用户加工需求"中给出的真实内容组织邮件；若需求未提供细节，使用合理示例数据并使其完整
- **当用户要求"重构 / 重新设计 / 换个主题 / 换风格"时，不要被现有页面的结构、卡片、配色束缚**——整体重建成一套新的邮件，而不是在原结构上只改颜色（具体替换动作见工作流程第 3 步）
- **重构时上面的"邮件结构"仅是兜底参考，不是必须照搬**：可采用通栏 Hero、左右分栏、时间线、杂志式排版等差异化构成，让版式与旧版明显不同；只要仍是得体、专业的录用通知文书即可
- 执行要点（plan）会指明内容层次，请参考
