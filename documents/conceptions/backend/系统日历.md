# 系统日历设计（企业级方案）

👉 基于

* Symfony + Doctrine ORM（后端）
* PostgreSQL（数据存储）
* jQuery + Twig（前端渲染）
* 免费公共 API（法定假日导入）

👉 **支持手动维护 + 网络导入，事务类型可自定义**

---

# 🚀 一、功能概述

系统日历是一个面向企业管理后台的日历模块，核心功能：

1. **法定假日管理** — 标注国家法定节假日，支持从公共 API 一键导入
2. **补班/调休管理** — 维护因节假日产生的补班工作日和调休休息日
3. **企业事务管理** — 记录公司活动、培训、会议、纪念日等自定义事务
4. **多视图展示** — 月视图 + 事务列表视图，一目了然
5. **类型可自定义** — 用户可以创建自定义事务类型，不限于预设分类

---

# 🧠 二、核心设计原则

### 1️⃣ 手动维护优先，导入为辅

* 所有事件都可以手动创建/编辑/删除
* 法定假日支持从网络 API 导入，但导入后仍可手动调整
* 导入操作为幂等操作：相同日期相同类型不会重复创建

### 2️⃣ 事务类型可扩展

* 系统预设 4 种基础类型：`holiday` / `workday` / `makeup_day` / `custom`
* 用户可在「事务类型管理」中自定义新类型（如：`company_event` / `training` / `anniversary`）
* 每个类型有独立的颜色标识和中文标签

### 3️⃣ 每年重复支持

* 固定的年度事件（如元旦、国庆）可设置为「每年重复」
* 重复规则以 JSON 存储，灵活支持：固定月日、某月第 N 个周几等

# 🌐 四、法定假日网络导入

## 数据源方案

### 方案 A：国务院办公厅公告解析（推荐）

使用免费公共 API 获取中国法定节假日数据：

| API | URL | 说明 |
|-----|-----|------|
| **TimOR API** | `https://timor.tech/api/holiday/year/{year}` | 免费、无需注册、含调休信息 |
| **Holiday CN** | `https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/{year}.json` | GitHub 开源数据，JSON 格式 |

### TimOR API 响应示例

```json
GET https://timor.tech/api/holiday/year/2026

{
  "code": 0,
  "holiday": {
    "01-01": { "holiday": true, "name": "元旦", "wage": 3, "date": "2026-01-01" },
    "01-02": { "holiday": true, "name": "元旦", "wage": 1, "date": "2026-01-02" },
    "01-04": { "holiday": false, "name": "元旦后补班", "wage": 1, "date": "2026-01-04" },
    ...
  }
}
```

**字段映射：**

* `holiday: true` → type = `holiday`（假日）
* `holiday: false` → type = `workday`（补班）
* `name` → 事件标题

### Holiday CN GitHub 数据

```json
{
  "year": 2026,
  "papers": ["..."],
  "days": [
    { "name": "元旦", "date": "2026-01-01", "isOffDay": true },
    { "name": "元旦", "date": "2026-01-02", "isOffDay": true },
    { "name": "元旦后补班", "date": "2026-01-04", "isOffDay": false },
    ...
  ]
}
```

**字段映射：**

* `isOffDay: true` → type = `holiday`
* `isOffDay: false` → type = `workday`

## 导入流程

```text
用户点击「导入法定假日」
        ↓
选择年份 + 数据源
        ↓
后端调用 API → 获取假日 JSON
        ↓
解析 JSON → 对每条记录：
  - 查重（相同 date + type 跳过）
  - 新增 SystemCalendarEvent 实体
        ↓
flush → 返回统计（新增N条，跳过M条）
        ↓
前端刷新日历视图
```

## 导入接口设计

```
POST /admin/calendar/api/import-holidays
Body: { "year": 2026, "source": "timor" }
Response: { "imported": 25, "skipped": 3, "errors": 0 }
```

# 📋 七、导入服务设计

## HolidayImportService

```php
class HolidayImportService
{
    // 从 TimOR API 导入
    public function importFromTimor(int $year): ImportResult;

    // 从 Holiday CN GitHub 导入
    public function importFromHolidayCN(int $year): ImportResult;
}
```

### ImportResult 值对象

```php
class ImportResult
{
    public int $imported = 0;   // 新增条数
    public int $skipped  = 0;   // 跳过条数（已存在）
    public int $errors   = 0;   // 错误条数
    public array $details = []; // 详细信息
}
```

### 导入逻辑核心

```php
foreach ($holidays as $item) {
    // 查重：同一日期 + 同一类型 → 跳过
    $existing = $repo->findOneBy(['date' => $date, 'type' => $type]);
    if ($existing) {
        $result->skipped++;
        continue;
    }

    $event = new SystemCalendarEvent();
    $event->setTitle($item['name']);
    $event->setType($item['holiday'] ? 'holiday' : 'workday');
    $event->setDate(new \DateTimeImmutable($item['date']));
    $event->setNote($this->generateNote($item));

    $em->persist($event);
    $result->imported++;
}
$em->flush();
```

# 🔄 八、与定时任务系统的联动

系统日历可与定时任务联动，支持：

1. **节假日跳过** — 定时任务可配置「遇法定假日跳过」选项
2. **工作日执行** — 通过查询系统日历判断当天是否为工作日
3. **事件触发任务** — 未来可扩展：在特定日历事件日自动触发关联任务

```php
// 在 TaskScheduler 中判断是否应跳过
if ($task->isSkipHolidays()) {
    $today = new \DateTimeImmutable('today');
    $isHoliday = $calendarRepo->findOneBy(['date' => $today, 'type' => 'holiday']);
    if ($isHoliday) {
        $this->logger->info("Task {$task->getName()} skipped due to holiday");
        return;
    }
}
```
