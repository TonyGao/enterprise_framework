# 定时任务系统设计（企业级方案）

👉 基于

* FrankenPHP（运行环境）
* Symfony Scheduler（调度思想）
* Symfony Messenger（执行引擎）
* PostgreSQL（队列 + 锁 + 数据）

👉 **无 Redis，企业级可扩展**

---

# 🚀 一、最终架构（定版）

```text
Crontab / K8s CronJob
        ↓
HTTP /internal/scheduler/run   （FrankenPHP）
        ↓
TaskScheduler（调度器）
        ↓
dispatch → Messenger
        ↓
PostgreSQL（队列表 messenger_messages）
        ↓
Messenger Worker（多进程）
        ↓
Task Handler（业务执行）
        ↓
task_log（执行记录）
```

---

# 🧠 二、核心设计原则（必须遵守）

### 1️⃣ 调度与执行彻底分离

* Scheduler：只负责“什么时候触发”
* Messenger：负责“执行”

---

### 2️⃣ 一切任务“数据化”

👉 数据库存任务，而不是写死代码

---

### 3️⃣ 并发安全（核心）

👉 必须用 PostgreSQL 锁机制

# 🔒 五、调度器（核心实现）

## TaskScheduler

```php
class TaskScheduler
{
    public function run(): void
    {
        $tasks = $this->connection->fetchAllAssociative("
            SELECT * FROM task
            WHERE enabled = true
              AND next_run_at <= NOW()
            ORDER BY next_run_at ASC
            LIMIT 50
            FOR UPDATE SKIP LOCKED
        ");

        foreach ($tasks as $task) {

            try {
                // 分布式锁（关键）：使用显式释放逻辑
                $locked = $this->connection->fetchOne(
                    'SELECT pg_try_advisory_lock(?)',
                    [$task['id']]
                );

                if (!$locked) {
                    continue;
                }

                $this->bus->dispatch(
                    new RunTaskMessage($task['id'])
                );

                // 更新执行时间：建议使用 dragonmantank/cron-expression 库计算
                $this->connection->executeStatement("
                    UPDATE task
                    SET last_run_at = NOW(),
                        next_run_at = :next
                    WHERE id = :id
                ", [
                    'next' => $this->calcNextRun($task['cron_expression']),
                    'id'   => $task['id']
                ]);
            } finally {
                // 显式释放锁，防止在长连接环境中产生僵尸锁
                $this->connection->executeStatement('SELECT pg_advisory_unlock(?)', [$task['id']]);
            }
        }
    }
}
```

## Handler（执行核心）

Handler 本身只负责找到任务、记录日志、委托给具体的业务 Runner 执行——这是"关注点分离"的关键。

```php
#[AsMessageHandler]
class RunTaskHandler
{
    public function __construct(
        private TaskRepository $taskRepository,
        private TaskLogRepository $taskLogRepository,
        private TaskHandlerLocator $taskLocator,
        private EntityManagerInterface $em,
    ) {}

    public function __invoke(RunTaskMessage $message): void
    {
        $task = $this->taskRepository->find($message->taskId);
        if (!$task || !$task->isEnabled()) {
            return; // 任务被删除或禁用，静默跳过
        }

        // 记录开始日志
        $log = new TaskLog();
        $log->setTask($task)
            ->setStatus('running')
            ->setStartedAt(new \DateTimeImmutable())
            ->setHostName(gethostname());

        $this->em->persist($log);
        $this->em->flush();

        $startTime = microtime(true);
        $memBefore = memory_get_usage(true);

        try {
            // 通过 Locator 模式解耦业务 Handler
            // Task.handler 字段存储 ServiceName，如 App\Task\SendEmailTask
            $runner = $this->taskLocator->get($task->getHandler());
            ob_start();
            $runner->handle($task->getPayload());
            $output = ob_get_clean();

            $log->setStatus('success')
                ->setOutput($output ?: null)
                ->setExecutionMs((int)((microtime(true) - $startTime) * 1000))
                ->setMemoryPeak(memory_get_usage(true) - $memBefore)
                ->setFinishedAt(new \DateTimeImmutable());
        } catch (\Throwable $e) {
            $log->setStatus('error')
                ->setOutput($e->getMessage())
                ->setExecutionMs((int)((microtime(true) - $startTime) * 1000))
                ->setFinishedAt(new \DateTimeImmutable());

            $this->em->flush();
            throw $e; // 重新抛出以触发 Messenger retry_strategy
        }

        $this->em->flush();
    }
}
```

## TaskHandlerLocator

通过 Symfony 的 `ServiceLocator` 机制实现按名称获取任务 Runner，避免直接依赖 ServiceContainer。

```php
// config/services.yaml 中注册
services:
  App\Service\Task\TaskHandlerLocator:
    arguments:
      $handlers: !tagged_locator { tag: 'app.task_handler', index_by: 'key' }
```

```php
class TaskHandlerLocator
{
    public function __construct(
        private ContainerInterface $locator
    ) {}

    public function get(string $key): TaskHandlerInterface
    {
        if (!$this->locator->has($key)) {
            throw new \RuntimeException("Task handler '{$key}' not found. Did you tag it with 'app.task_handler'?");
        }
        return $this->locator->get($key);
    }
}
```
