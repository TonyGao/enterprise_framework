AI Mate: project diagnostic tools, exposed through the `vendor/bin/mate` CLI.

- Provenance: this block is generated by `vendor/bin/mate discover`. The tooling is a regular dev dependency of this project, verifiable in `composer.json` (`symfony/ai-mate`); the binary lives at `vendor/bin/mate`.
- Invocation: always run Mate as `vendor/bin/mate`; another interpreter reports on a runtime that is not this application's, and Mate refuses to start under one.

- Installed extensions: symfony/ai-mate, symfony/ai-symfony-mate-extension.

## Internationalization (i18n) / 国际化

The system is internationalized (zh_CN / en, extensible). When adding or modifying UI strings, templates or emails, follow the conventions in `documents/i18n-guide.md` / `documents/i18n-guide.zh-CN.md`:

- Server-side (Twig): `{{ 'key'|trans }}`, keys added to BOTH `translations/messages.zh_CN.yaml` and `messages.en.yaml`.
- Frontend (JS): `t('key')`, never hardcode Chinese in JS.
- API errors: pass a translation key as the API `code`; frontend uses `window.apiMsg(xhr)`.
- Email templates: multi-language via `sys_email_template.locale` (editor language switcher + locale-aware send).
- New source comments should be bilingual: `/** 中文 / English */`.
- Verify: `php bin/console ef:i18n-scan` (expect 0 missing keys, no hardcoded CJK).

本系统已国际化（zh_CN / en，可扩展）。新增或修改界面文案、模板、邮件时，请遵循 `documents/i18n-guide.md` / `documents/i18n-guide.zh-CN.md` 中的约定：服务端用 `|trans` 且 key 成对写入双语 messages 文件；前端用 `t('key')` 禁止硬编码中文；API 错误用 `code` 传 key；邮件模板多语言存于 `sys_email_template.locale`；新增源码注释尽量 `/** 中文 / English */`；用 `ef:i18n-scan` 验证。
